---
description: 내 이름 폴더의 변경만 골라 확인받고 올린다
---

1. `CLAUDE.local.md`에서 내 이름 폴더를 읽는다. 없거나 `[확인 필요`로 시작하면 멈추고 묻는다.
2. `git pull`을 실행한다.
3. `git status`로 바뀐 파일을 아래 표로 보여 주고 **기다린다**.

| 파일 | 새로/고침 | 내 이름 폴더 안인가 |
|---|---|---|

   내 이름 폴더 밖 파일이 있으면 표에서 표시하고, 올릴지 따로 묻는다.
4. 사용자가 "좋아"라고 하면 표의 그 파일만 `git add` 한다(`git add .`, `-A` 금지).
5. `git commit -m "내 이름: 한 일 한 줄"`
6. `git push`
7. push가 rejected 되면 `git pull` 뒤 다시 `git push` 한다.
8. 같은 파일이 부딪힐 때(conflict)만 멈춘다. 아무것도 지우지 말고 두 판을 나란히 보여 주고, 합칠 안을 묻는다.
